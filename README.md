# Superfit

Responsive fitness landing page built with HTML, SCSS, JavaScript and Gulp.

<img width="1011" height="497" alt="image" src="https://github.com/user-attachments/assets/381fd0bd-8050-4e84-bfc7-8bd1c1c9b40f" />

**Live Demo**: [ponidevito.github.io/xbox](https://ponidevito.github.io/superfit/)

## Technologies

- HTML5
- SCSS
- Gulp
- BEM methodology

## Features

- Responsive layout
- Optimized images
- SEO meta tags
- Open Graph support
- Lazy loading images

## Installation

```bash
npm install
```

## Run project

```bash
gulp
```

## Build project

```bash
gulp build
```
